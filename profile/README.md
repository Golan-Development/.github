## About Us

**Golan Development** is a professional software development organization building high-quality, enterprise-grade products. We follow the **Open Core** model — our core platform is source-available and community-friendly, while advanced enterprise capabilities are delivered commercially. Like MinIO, GitLab, or HashiCorp: transparent at the foundation, powerful at scale.

## Contributing

We welcome community contributions to the **open core edition** of our projects. Here's how to get involved:

```bash
# 1. Fork the repository, then clone your fork
git clone https://github.com/<your-username>/<repo>.git

# 2. Create a feature branch
git checkout -b feat/your-feature-name

# 3. Commit your changes following Conventional Commits
git commit -m "feat: add your feature"

# 4. Push and open a Pull Request against main
git push origin feat/your-feature-name
```

**Before submitting, please ensure you:**
- Follow the existing code style and conventions
- Write or update tests where applicable
- Update documentation where needed
- Are respectful and constructive in reviews

> ⚠️ **Note:** Repositories may contain both a community-licensed core and proprietary enterprise modules. External contributions are accepted for the community core only. Enterprise features are maintained internally by the Golan Development team.
